✍️

Escriba en cada tarjeta el ID completo que aparece en la lista. El ID sigue la estructura COL-[municipio]-[comunidad]-[tipo]-[número], por ejemplo COL-1-2-3-04. Esto permite vincular las respuestas pre y post de cada participante.

🎴

Entregue a cada participante su tarjeta de condición (0 o 1) según la lista de arriba. Los participantes con condición 0 recibirán el cuestionario placebo; los de condición 1 recibirán el cuestionario PRE.
